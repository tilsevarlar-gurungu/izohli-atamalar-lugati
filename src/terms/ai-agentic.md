# Vakolatli

**Inglizça:** Agentic<br>
**Rusça:** Агентный<br>
**Soha:** Suniy Ong<br>

**Vakolatli** — Suniy Ong tizimining taşqi körsatmalarga faqat kör-körona javob qaytarmay, berilgan topşiriqni bajariş uçun mustaqil qarorlar qabul qiliş, reja tuziş va amallarni bajariş qobiliyati. Bunday hususiyatga ega tizimlar öz maqsadiga erişiş uçun bir neçta bosqiçli jarayonlarni öz hohişi va mantiqiy tahlili asosida boşqara oladi. Vakolatli SO vakillar orqali işlaydi.

Vakolatli SO'ning havfli taraflaridan biri - aljiraş oqibatida zararli qarorlar qabul qilişi va amalga oşirişidir.

```
+-------------------------------------+
|        VAKOLATLI SO TIZIMI          |
|  Maqsad -> Rejalaştiriş -> Bajaruv  |
|                   ^                 |
|                   | (Moslaşuv)      |
|             Muvaffaqiyat            |
+-------------------------------------+

```
